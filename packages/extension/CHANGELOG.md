# Changelog

## 0.1.1

- VS Code's own side-by-side diff (clicking a changed file in Source Control) now highlights changes: the left side shows removed parts in red, the right side added parts in green, changed areas are boxed, and pan/zoom is synced. A banner gives the change count, a change list, and a button to open the full KiCad diff.
- More reliable pairing of the two sides of that diff.
- Overlay: unchanged lines no longer show a faint red/green tint at low zoom.
- A new diff opens on the first sheet that has changes.

## 0.1.0

- First release: schematic and PCB viewer, visual diff (overlay, side by side, blend, swipe) and semantic change list, git integration.
